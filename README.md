# Brinda Soni & Associates — Website

Marketing site for [Brinda Soni & Associates](https://bsaadvisors.in), a Practicing Company Secretary firm based in Ahmedabad. Built with Next.js 15 (App Router), Tailwind CSS v4, shadcn/ui, and Framer Motion. Deploys to Vercel with zero environment variables.

## Quick start

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm build        # production build
pnpm lint         # ESLint
```

Requires Node 20+ and pnpm 9+ (the repo pins `pnpm` via `corepack`).

## Editing the site

The site is intentionally architected so almost every change happens in **one of two files**.

### Edit content → `lib/site-config.ts`

This is the single source of truth for every word, service, FAQ, testimonial, and metadata field on the site. Components don't hardcode copy — they all read from `siteConfig`. Open the file, change the value, save.

Common edits:

- **Hero headline / subhead** → `siteConfig.hero`
- **Services** → `siteConfig.services` (six categories, each with title, icon, description, sub-items)
- **Why Choose Us bullets** → `siteConfig.whyChooseUs`
- **Industries pills** → `siteConfig.industries`
- **FAQs** → `siteConfig.faqs` (also feeds the FAQPage JSON-LD for rich results)
- **Testimonials** → `siteConfig.testimonials` (currently placeholders — replace before launch)
- **Contact email / location / LinkedIn** → `siteConfig.contact`
- **Founder bio + credentials** → `siteConfig.founder`
- **SEO meta + keywords** → `siteConfig.seo`

### Edit theme → `app/globals.css`

Colors, fonts, spacing, and shadows live in the `@theme` block at the top of the file.

- **Change brand color**: edit `--color-brand-500` (currently navy `#1a2a52`). The 50–900 scale around it can be regenerated with any standard palette generator.
- **Change accent color**: edit `--color-accent-500` (currently champagne `#c9a961`).
- **Change surface colors**: `--color-paper`, `--color-paper-tinted`, `--color-ink`.

The `:root { ... }` block below maps these to shadcn's semantic tokens (`--primary`, `--ring`, etc.) so the Button / Accordion components track the brand automatically.

### Swap the founder photo

Drop a portrait at `public/brinda-soni.jpg` (recommended **800×1000**, JPG or AVIF, optimized).

If the file is missing the site falls back to a navy block with "BS" Fraunces initials — so you'll never ship a broken image. The fallback logic lives in `components/shared/founder-portrait.tsx`.

## Project structure

```
app/
  layout.tsx              # fonts, metadata, JSON-LD, analytics, skip link
  page.tsx                # composes section components in order
  globals.css             # @theme tokens — single point for design changes
  opengraph-image.tsx     # dynamic 1200x630 OG card
  twitter-image.tsx       # re-exports OG
  icon.tsx, apple-icon.tsx # dynamic favicons
  sitemap.ts, robots.ts, manifest.ts
components/
  layout/   header, mobile-menu, footer
  sections/ hero, about, services, why-us, industries, international,
            testimonials, faq, contact
  shared/   fade-in, section-heading, wordmark, icsi-badge,
            founder-portrait, linkedin-icon
  seo/      json-ld
  ui/       shadcn primitives (button, accordion)
lib/
  site-config.ts          # ALL content
  theme.ts                # JS-side motion / breakpoint tokens
  utils.ts                # cn() helper
public/
  brinda-soni.jpg         # founder photo (drop-in optional)
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. Go to <https://vercel.com/new>, import the repo. No env vars needed.
3. Verify the production URL.
4. Point `bsaadvisors.in` DNS at Vercel (in the Vercel project's Domains tab).

The OG image is generated at build via `app/opengraph-image.tsx` and cached on Vercel's edge.

## SEO surface

- Page metadata, canonical, Open Graph, Twitter cards — `app/layout.tsx`
- Structured data: **LegalService**, **Person** (with ICSI membership), **FAQPage** — `components/seo/json-ld.tsx`
- Sitemap, robots.txt, web manifest — generated by `app/sitemap.ts`, `app/robots.ts`, `app/manifest.ts`
- Dynamic OG / Twitter card image — `app/opengraph-image.tsx`

## Accessibility

- Single h1, one h2 per section, semantic landmarks (`<header>`, `<main>`, `<section aria-labelledby>`, `<footer>`)
- Skip link to `#main`
- Champagne focus ring on every interactive element
- Mobile menu: focus-managed, `aria-expanded` / `aria-controls`, ESC closes
- All Framer Motion components honor `prefers-reduced-motion`
- Image alt text and accessible mailto labels
